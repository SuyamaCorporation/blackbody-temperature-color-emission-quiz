# Blackbody Temperature & Color Emission Quiz

Quiz testing knowledge of blackbody radiation: Wien displacement law, Stefan-Boltzmann law, and temperature-color relationships.

## Features
- 10 multiple choice questions covering Wien's Law, Stefan-Boltzmann Law, stellar classification, and real-world applications
- Live blackbody color visualizer with temperature slider (1,000 K – 40,000 K)
- Peak wavelength calculation and color identification per temperature
- Star-type examples (M, K, G, F, A, B, O spectral classes)
- Instant feedback with detailed explanations for each answer
- Progress tracker with color-coded dots
- Key formulas reference panel with temperature-color guide
- Final score summary with performance assessment

## Usage
1. Answer each multiple choice question about blackbody radiation
2. Click an answer to see if you were correct, with a full explanation
3. Use the color visualizer on the right to explore how temperature maps to color
4. Study the formulas panel for reference
5. Review all 10 questions then restart to improve your score
